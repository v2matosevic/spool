# Changelog

## 1.5.1

- First public release preparation, contributor/security guides and native release automation.
- Matching-only Spotify helper excludes the unused obsolete web-server dependency stack.
- Correct macOS resource/code layout and console-capable app entry point.
- Per-user defaults for fresh installations; stored destinations and previous install directories are preserved.

## 1.5.0

- Flat batches with a destination specific to the batch and stable collision-resistant filenames.
- Copy path and guarded native Windows file dragging for completed media.

## 1.4.0

- Local structured diagnostics with redaction, retention, reference IDs and offline CLI/MCP export.

## 1.3 series

- Spool identity, redesigned interface, reversible history cleanup, Retry failed and searchable library.
- Windowed Windows launcher and shared taskbar/shortcut identity.

## 1.2.0

- Isolated Spotify-track metadata matching against YouTube, with source provenance and audio tagging.

## 1.1.0

- Native desktop packaging, explicit output containers, folder picker, platform catalog, CLI and MCP.

These describe implemented features, not a guarantee that every upstream platform, account or target application works. See each release for exact build and verification evidence.
