Command line

The desktop executable takes commands and answers in JSON, with job IDs, progress and finished file paths.

VideoDownloader.exe --cli download "VIDEO_URL" --format mp4 --wait
VideoDownloader.exe --cli status
VideoDownloader.exe --cli retry-failed
VideoDownloader.exe --cli platforms bluesky

Formats: original, mp4, mp4-best, mkv, webm, audio, mp3, m4a, flac, wav. Add --folder "D:\Downloads\Research" to send one batch somewhere else.

Posts that need a login

          
Pick a browser session under Sign-in when you download. The engine reads that browser's cookies locally; no password is asked for. If Windows blocks browser cookies, import a cookies.txt export from your own session instead.

          
No cookie file imported

          
The file stays in this app's local folder. Treat it like a password, and only choose a session for sites you want Spool to read.

        

        

          
Download engine

          

          
Platforms change often. From source, run Update engine.cmd and restart the app. The packaged app updates with a new build. Your library and settings are stored separately and survive both.

        

        

          
Spotify songs

          
Checking the song matcher…

          
Paste a Spotify track link, or several. Spotify supplies artist, album and cover; spotDL finds a matching YouTube recording, and that recording sets the audio quality. Preview shows the match before you download. FLAC or WAV can't restore detail the source never had.

          
Public tracks need no Spotify login or developer key. Matching is automatic and can occasionally pick another version, so check Preview when the exact recording matters.

        

        

          
Quality and clean sources

          
Original keeps the best available video and audio without re-encoding. MP4 · plays everywhere picks H.264 video with AAC audio, which can mean a lower resolution. Original audio avoids a lossy conversion; MP3 trades a little fidelity for compatibility. Nothing is ever upscaled.

          
Skip watermarked sources rejects formats explicitly marked as watermarked, such as TikTok's download copies. It doesn't crop, blur or reconstruct video. Profiles, playlists and live streams are excluded; paste individual links instead.
